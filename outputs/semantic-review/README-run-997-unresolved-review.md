# PrintVault unresolved review batch

This 20-file batch was selected from run #997's unresolved records. The user reviewed the files against the actual models: 17 received a category and semantic label; three were marked “not found” and intentionally remain unlabeled.

The labeled CSV preserves the user-provided category and semantic type. The `HumanArtifactForm` field is left blank wherever the user did not provide a separate physical-form description. Do not infer extra labels from filenames or metadata.

Supported categories: Functional; Terrain & Props; Figures & Characters; Vehicles; Household; Tools & Workshop; Toys & Games; Art & Decor; HueForge; Keychains; Buildings; Nature & Scenery; Tabletop Terrain; Props & Accessories; Uncategorized.

The current semantic rules use the reviewed evidence conservatively. Where the same subject has a different physical form (for example, a Death Star model versus a 200x200 Death Star HueForge tile), the rule uses a more specific title phrase and the other form remains unresolved. The three “not found” records also remain unresolved.

This is a selected diagnostic sample, not a statistical accuracy estimate. Future rule families should have user-labeled positives and nearby negative controls, then be replayed across the complete unresolved set before being accepted.
